# 2026-VK-EDU-Web-12-Mitskevich-A

## Как запустить/открыть верстку
Открыть файл `public/index.html` в любом современном браузере.

## public/base.html — базовый макет страницы.

public/index.html — список новых вопросов.

public/hot.html — список популярных вопросов.

public/tag.html — вопросы по тегу.

public/question.html — вопрос, ответы и форма ответа.

public/ask.html — форма создания вопроса.

public/login.html — форма входа.

public/signup.html — форма регистрации.

public/profile.html — настройки профиля.
